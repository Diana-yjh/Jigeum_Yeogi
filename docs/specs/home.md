# 홈 탭 (home)

역할에 따라 완전히 다른 화면. `lib/features/home/teacher_home_screen.dart`, `parent_home_screen.dart`.

---

## 선생님 홈 (TeacherHomeScreen)

### 목적
오늘 등원해야 하는 아이들과 등원 현황을 한눈에.

### 화면 구성
- 상단: 오늘 날짜(`M월 D일 O요일`) + 제목 "오늘 등원 예정"
- **등원 현황 카드**(primary 배경): `등원 인원 / 예정 인원` + 진행 바
- **오늘 등원 예정 리스트**: 스케줄상 오늘 요일에 잡힌 학생. 각 행에
  - 이름, **정규/보충**(보충이면 "보충" 태그)
  - 등원 예정 시각(`등원 예정 오후 3:00`)
  - 상태: 등원 전 / `HH:mm 등원`(수업 중) / 하원 완료 / 하원 완료 선택 시 "기록을 초기화 하시겠습니까?" 알림 토글
- 빈 상태: "오늘 등원 예정인 학생이 없어요. 스케줄 탭에서 요일을 지정해보세요."

### 데이터
- `todayScheduledStudentsProvider`(스케줄에서 오늘 요일 학생, 시간순) + `teacherTodayRecordsProvider`.

# 홈 화면 (학부모)

전제: `design/CLAUDE.md`의 토큰과 공통 컴포넌트를 쓴다.

## 목적

앱을 열자마자 "우리 아이가 지금 어디 있는지"가 1초 안에 읽혀야 한다. 나머지는 전부 보조.

## 레이아웃 (위→아래)

세로 스크롤 가능한 `ListView`. 좌우 패딩 16, 항목 간 간격 10.

1. 헤더
2. 오늘 상태 히어로 카드
3. 이번 주 출석 카드
4. 선생님 채팅 미리보기 카드
5. `ParentTabBar` (홈 활성)

### 1. 헤더

- 좌: `ChildAvatar(size: 36)` + 오른쪽에 두 줄
  - 1줄: 아이 이름, 20 / w600
  - 2줄: `학원명 · 학년` 12 / textSecondary. 학년 데이터 없으면 학원명만.
- 우: 종 아이콘, textSecondary. 탭하면 **알림 목록 화면**으로 이동한다.
  - 마지막으로 알림함을 연 뒤(`users.notificationsSeenAt`) 새로 생긴 알림이 있으면 우상단에 primary 점을 띄운다.
  - 알림 목록은 별도 컬렉션 없이 최근 30일 `attendance` 기록의 등원·하원 시각에서 만들어낸다.
    자녀 전체를 합쳐 최신순으로 보여주고, 날짜별(오늘/어제/M월 d일)로 묶는다.
  - 문구는 실제 발송을 담당하는 `functions/index.js`와 같게 유지한다.
- 기존의 "우리 아이" 라벨 + 큰 이름 두 줄 구조는 삭제한다.

### 2. 오늘 상태 히어로 카드

배경 `primary`, 글자 흰색, radius 16, padding 16. 화면에서 유일한 오렌지 면.

상태 3가지. `todayAttendance`로 분기한다.

| 상태 | 조건 | 상단 pill | 제목 | 타임라인 |
|---|---|---|---|---|
| 등원 전 | 오늘 기록 없음 | `등원 전` | `아직 등원 전이에요` | 양쪽 점 모두 비어 있음(테두리만) |
| 학원에 있어요 | 등원만 있음 | `학원에 있어요` | `지금 학원에 있어요` | 왼쪽 점 채움, 오른쪽 점 비움, 선은 왼쪽 절반만 채움 |
| 하원 완료 | 등원+하원 모두 있음 | `하원 완료` | `집에 잘 갔어요` | 양쪽 점 채움 |

카드 내부 구성
- 1행: 좌 `StatusPill(filled: true)` / 우 `목 8/27` 12, opacity 0.85
- 2행: 제목 16 / w600, 위아래 여백 10 / 12
- 3행: 타임라인 Row
  - 좌 컬럼: `등원` 12 opacity 0.8 위, 시각 14 / w600 아래
  - 중앙: `Expanded` 높이 3 선(흰색 0.35). 양 끝에 지름 9 원. 채움 상태는 위 표.
  - 우 컬럼: `하원` + 시각. 시각 없으면 `--:--`
- 4행: 중앙 정렬 캡션 12 opacity 0.9
  - 하원 완료: `3시간 50분 머물렀어요`
  - 학원에 있어요: `12:51부터 학원에 있어요`
  - 등원 전: 표시 안 함

시각 표기는 24시간 `HH:mm`. 오전/오후 접두어 쓰지 않는다.

### 3. 이번 주 출석 카드

`AppCard`.
- 1행: 좌 `이번 주` 14 / w600, 우 `1 / 3회` 12 textSecondary. 분모는 이번 주 수업 예정 일수(스케줄 데이터 없으면 분모 생략하고 `1회`만).
- 2행: 월~일 7칸 `Row(mainAxisAlignment: spaceBetween)`. 각 칸은 요일 라벨 12 + 아래 지름 22 원.
  - **원은 수업이 있는 날에만 그린다** — 원 개수 = 주당 수업 횟수. 채워진 원은 출석 하나뿐이다.
  - 출석한 날: 원 배경 primary, 흰 체크 아이콘. 요일 라벨도 primaryDeep.
  - 오늘이 수업일이고 아직 등원 전: primary 테두리 2, 안은 비움. 라벨 primaryDeep.
  - 지난 수업일인데 출석 없음: cardBorder 테두리 빈 원 + 가운데 `×` textFaint. (채운 회색 원은 "체크됨"으로 오독된다)
  - 아직 안 온 수업일: cardBorder 테두리 빈 원.
  - 수업 없는 날: 원 없음. 오늘이면 라벨만 primaryDeep.
- 주 시작은 월요일.

### 소속 선생님 칩
학부모가 **선생님을 2명 이상 연결**했으면, 아이 이름 옆(다자녀 페이저) 또는 히어로 카드 위(단일 자녀)에 소속 선생님 칩을 표시한다 — 색 도트 + 닉네임, 그 색 12% 배경 pill.
- 색은 `AppUser.teacherDirectory`(정렬된 코드 순)의 인덱스로 `AppColors.childColor(i)` 배정 — 화면 간에 흔들리지 않는다.
- 내보내진 아이(`teacherCode` 빈 값)는 회색 "연결된 선생님 없음".
- 선생님이 1명이면 칩을 표시하지 않는다.

### 자녀가 여러 명일 때
헤더 이름은 "우리 아이들"로 두고, 그 아래를 **좌우 스와이프 페이저**로 만든다.
한 페이지 = 아이 한 명이며, 페이지 안은 **[이름 → 히어로 카드 → 이번 주 출석 카드]**로
단일 자녀 화면과 같은 구성을 그대로 쓴다. 하원 타임라인과 주간 출석이 아이별로 모두 보인다.

- 세로로 쌓지 않는다. 아이가 늘어도 화면이 길어지지 않게 한 번에 한 명만 보여준다.
- 화면 아래에 페이지 점을 고정한다(현재 페이지만 길쭉한 알약).
- 페이지 안쪽은 세로 스크롤 가능(글씨 확대 시 내용이 길어질 수 있다).
- 자녀가 삭제되면 현재 페이지 인덱스가 범위를 벗어날 수 있으므로 clamp 한다.

- 주간 기록(`childWeekRecordsProvider`)은 자녀 전체가 한 번에 오므로, 카드에 넘길 때 `studentId`로 걸러야 한다.
  거르지 않으면 아이별 출석 횟수가 형제 것까지 합산된다.
- 오늘 기록은 `studentTodayRecordProvider(studentId)`로 아이별로 받는다.

### 4. 선생님 채팅 미리보기

`AppCard(padding: EdgeInsets.symmetric(h: 12, v: 10))`, 탭하면 채팅 탭으로 이동.
- 좌: 지름 30 원, 배경 primaryTint, 말풍선 아이콘 16 onPrimaryTint
- 중: 선생님 이름 14 / w600, 아래 마지막 메시지 12 textSecondary, 한 줄 ellipsis
- 우: 안 읽은 메시지 있으면 지름 8 primary 점
- 메시지가 하나도 없으면 중앙 텍스트를 `선생님께 메시지를 보내보세요` textSecondary로.

## 데이터

```dart
class TodayAttendance {
  final DateTime? checkIn;   // 등원
  final DateTime? checkOut;  // 하원
  final String type;         // '정규' | '보강' 등
}
class WeekAttendance {
  final Map<int, DateTime?> checkInByWeekday; // 1(월)~7(일)
  final Set<int> scheduledWeekdays;
}
```
Firestore 실시간 구독으로 히어로 카드 상태가 즉시 바뀌어야 한다(선생님이 등원 체크하면 학부모 화면이 바로 갱신).

## 하지 말 것

- 히어로 카드 외에 오렌지 배경 면을 추가하지 않는다.
- "총 3시간 50분" 같은 정보를 두 번 보여주지 않는다(홈에서는 히어로 캡션 한 곳만).
- 기존 "이번 주 출석" 카드의 날짜별 리스트 행(목 8/27 | 시간 | 정규)은 삭제한다. 그 정보는 달력 탭에 있다.
