# 탭별 상세 요구사항 (specs)

각 탭의 상세 요구사항 문서. **해당 탭을 작업하기 전에 반드시 읽는다.**

| 탭 | 역할 | 파일 |
|----|------|------|
| 홈 | 선생님·학부모 | [home.md](home.md) |
| 출석 | 선생님 | [attendance.md](attendance.md) |
| 스케줄 | 선생님 | [schedule.md](schedule.md) |
| 달력 | 학부모 (+선생님 달력) | [calendar.md](calendar.md) |
| 설정 | 공통 | [settings.md](settings.md) |

- 선생님 탭: 홈 / 출석 / 스케줄 / 설정
- 학부모 탭: 홈 / 달력 / 설정
- 온보딩(역할 선택·로그인·회원가입)은 탭이 아니며 별도 문서 없음.
