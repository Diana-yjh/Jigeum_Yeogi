학원 등하원 알림장 — 선생님이 등원·하원을 체크하면 학부모 휴대폰으로 바로 알림이 갑니다.

자주 묻는 질문

선생님 코드가 뭔가요?

선생님이 가입하면 자동으로 발급되는 6자리 숫자입니다. 선생님 앱의 설정 → 우리 반 코드에서 확인·복사할 수 있어요. 학부모는 이 코드와 아이 이름만 입력하면 연결됩니다.

학부모인데 아이를 어떻게 연결하나요?

  1. 회원가입 때 선생님 코드 + 아이 이름을 입력하면 바로 연결됩니다.
  2. 아이를 더 추가하려면 설정 → 우리 아이 → 아이 추가.
  3. 다른 학원(선생님)도 다니면 설정 → 선생님 → 선생님 추가로 코드를 등록한 뒤, 아이 추가에서 그 선생님을 선택하세요. 선생님마다 닉네임과 구분색을 정할 수 있어요.

등원·하원 알림이 안 와요

  • 앱 설정 → 알림에서 등원/하원 알림이 켜져 있는지 확인하세요.
  • 휴대폰 설정 → 알림 → 오늘출석에서 알림 허용이 켜져 있는지 확인하세요.
  • 알림을 놓쳤다면 홈 오른쪽 위 종 아이콘에서 지난 알림을 다시 볼 수 있어요.

지난 출결 기록은 어디서 보나요?

학부모는 달력 탭에서 월별 기록과 날짜별 등원~하원 시간을, 선생님은 출석 화면 오른쪽 위 달력 아이콘에서 반 전체 기록을 볼 수 있어요.

선생님인데 학생을 반에서 빼고 싶어요

스케줄 탭 → 학생 선택 → 오른쪽 위 내보내기. 학부모 앱에는 아이와 지난 기록이 남고 선생님과의 연결만 해제됩니다.

계정을 삭제하고 싶어요

앱 설정 → 회원탈퇴에서 바로 삭제할 수 있습니다. 자세한 안내와 이메일 요청 방법은 계정 삭제 안내를 참고하세요.

문의하기

해결되지 않는 문제나 제안이 있으면 이메일로 보내주세요. 영업일 기준 2~3일 안에 답변드립니다.

가입한 이메일 주소와 함께, 문제가 발생한 화면·시간을 적어주시면 더 빨리 도와드릴 수 있어요.
