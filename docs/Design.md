# 지금여기 — 디자인 문서

앱 전반의 디자인 시스템과 화면별 구성. 색·간격·글자는 **토큰만 사용**하며 위젯에서 직접 값(`Color(0xFF...)`, 하드코딩 크기)을 쓰지 않는다. 토큰 정의: `lib/core/theme/`.

## 톤 & 원칙
- **소프트 파스텔 + 웜 뉴트럴**. 브랜드는 클레이 오렌지(코랄) 계열 유지, 채도는 낮춰 세련되게.
- **큰 라운드(24) + 부드러운 웜톤 그림자**로 가볍고 산뜻하게(하드 테두리 지양).
- 히어로 카드는 코랄 **그라디언트**로 포인트. 보조로 어시 파스텔 **세이지**를 소량 사용.
- 역할별 화면 완전 분리(선생님=관리 대시보드, 학부모=내 아이 안심).
- `ColorScheme.fromSeed(seedColor: primary)` 기반 Material 3 + `scaffoldBackgroundColor` 오버라이드.

## 간격 / 모서리 / 그림자 (`app_dimens.dart`)

- **AppSpace**: `xs 4` · `sm 8` · `md 16` · `lg 24` · `xl 32` · `xxl 40`
- **AppRadius**: `sm 14` · `card 24` · `chip 18` · `pill 999`
- **AppShadow.soft**: 웜톤 8% 블러 24 · y+10 (+ 미세 그림자). 카드 기본 그림자.

## 공용 데코레이션 (`app_decorations.dart`)
- `AppDecoration.card()` — 흰 카드 + 소프트 그림자(테두리 없음).
- `AppDecoration.hero()` — 코랄 그라디언트 히어로.
- `AppDecoration.tint(color)` — 은은한 색면(그림자 없음).

## 컴포넌트 패턴

- **카드**: `AppDecoration.card()` — 흰 배경 + radius 24 + 소프트 그림자.
- **히어로 카드**: `AppDecoration.hero()` — 선생님 홈 "등원 현황", 학부모 "지금 학원에 있어요".
- **필터 칩**(출석): pill. 선택=채워진 `primary`+흰 글자, 비선택=`primarySoft`+`textSub`.
- **상태 버튼**(학생 카드): 등원 전=아웃라인 "등원", 등원함=채워진 `primary` "하원", 완료/결석=상태 pill.
- **세그먼트 토글**(스케줄): `chipNeutral` pill 트랙 위에 흰 pill이 슬라이드(180ms). 선택=흰 pill+소프트 그림자+`primaryDeep` 굵게.
- **요일 토글**(스케줄 상세): 원형. on=`primary`+흰 글자, off=`chipNeutral`.
- **정규/보충 태그**: 정규=`sageSoft`/`sageDeep`, 보충=`primarySoft`/`primaryDeep` pill.
- **진행 바**(선생님 홈): 그라디언트 카드 위 흰색 `LinearProgressIndicator`.
- **다이얼로그**: 둥근 모서리(24)·틴트 제거. 제목+질문+[취소 / 실행(=`primaryDeep`)].
- **하단 탭**: `NavigationBar` 높이 66, 배경 `card`, 인디케이터 `primarySoft`, 선택 아이콘 `primaryDeep`.
- **달력 셀**: 등원=`primarySoft`, 오늘=`primaryDeep`, 선택=`primary` 테두리. 요일 한글, 제목 `yyyy년 M월`.

## 화면별 디자인

### 온보딩 / 인증
- **시작 화면**: `display` 36pt "지금여기" + 안내, 역할 선택 카드 2개(소프트 그림자, 아이콘 원형 `primarySoft`, `>`).
- **로그인·회원가입**: 라벨+필드(채운 `card`, 포커스 `primary` 테두리), 하단 채워진 pill 버튼.

### 홈 (선생님)
- 날짜 + "오늘 등원 예정" 제목.
- **등원 현황 히어로**(그라디언트): `등원/예정 명` + 흰 진행 바.
- 예정 학생 리스트(소프트 카드): 이름(+보충 태그)·예정 시각·상태. 하원 완료 행 탭→초기화 확인(↻).

### 홈 (학부모)
- "우리 아이" + 자녀 이름.
- **라이브 상태 카드**: 수업 중이면 그라디언트 히어로, 그 외 흰 카드.
- **주간 출석 기록 카드**: "이번 주 출석 N회" + 날짜별(요일·날짜·등하원·정규(세이지)/보충(피치)).

### 출석 (선생님)
- 날짜 + "오늘 출석" + 우측 달력 아이콘. 필터 칩 + 학생 카드 리스트.

### 스케줄 (선생님)
- "오늘(요일) 예정 N명" + **세그먼트 토글**[학생별 설정 / 월간 보기].
- 학생 목록(소프트 카드·요약·보충 태그·`>`) → 상세(요일 스위치+시간 드롭다운+정규/보충 칩+저장).
- 월간 보기: 달력 + 선택일 예정 명단.

### 달력 (학부모)
- "출결 달력" + 월 달력. 날짜 탭 → 등원~하원 타임라인·총 체류·요약 카드.

### 설정 (공통)
- 내 정보 카드. 선생님 "우리 반 코드" 카드(`primarySoft`). 로그아웃 버튼 → 확인 다이얼로그.

## 규칙
- 색·간격·글자·모서리·그림자는 반드시 토큰(`AppColors`/`AppSpace`/`AppRadius`/`AppShadow`/`AppText`) 또는 `AppDecoration` 사용. 새 값이 필요하면 토큰을 먼저 추가.
- 흰 카드는 `AppDecoration.card()`로 통일(하드 테두리 지양).
- 온-프라이머리(코랄 위) 텍스트/아이콘은 흰색 계열 허용.
